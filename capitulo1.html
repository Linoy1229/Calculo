Sumas

Notación sigma, propiedades y suma de Riemann con rectángulos inscritos y circunscritos.

Definición y propiedades

La notación sigma abrevia una suma de términos que siguen una misma regla. Se lee: “suma de f(i) desde i = m hasta n”.

DefiniciónΣi=mn f(i) = f(m) + f(m+1) + … + f(n)

Ejercicio 1.1 · Sumas por desarrollo

Calcula el valor de cada suma escribiendo sus términos.

Ejemplo 1

Σi=14 i²

  1. Se sustituye i = 1, 2, 3, 4 en la expresión i².
  2. Se escribe cada término: 1² + 2² + 3² + 4².
  3. Se calcula: 1 + 4 + 9 + 16.

Resultado: 30

Ejemplo 2

Σk=15 (2k + 1)

  1. Se evalúa la expresión para k = 1, …, 5.
  2. Los valores son 3, 5, 7, 9 y 11.
  3. Se suman: 3 + 5 + 7 + 9 + 11.

Resultado: 35

Ejemplo 3

Σi=36 i (el índice no empieza en 1)

  1. El índice inicia en 3, así que los términos son i = 3, 4, 5, 6.
  2. Se suman: 3 + 4 + 5 + 6.

Resultado: 18

Ejemplo 4

Σi=14 1/i

  1. Se escriben los términos: 1 + 1/2 + 1/3 + 1/4.
  2. Denominador común 12: 12/12 + 6/12 + 4/12 + 3/12.
  3. Se suman los numeradores: 25/12.

Resultado: 25/12

Ejemplo 5

Σn=03 2n

  1. El índice empieza en 0: 2⁰, 2¹, 2², 2³.
  2. Los valores son 1, 2, 4 y 8.
  3. Se suman: 1 + 2 + 4 + 8.

Resultado: 15

Ejercicio 1.2 · Sumas con propiedades

Estas reglas y fórmulas evitan sumar término por término.

ConstanteΣi=1n c = c n
Constante multiplicandoΣ c f(i) = c Σ f(i)
Suma de funcionesΣ [f+g] = Σ f + Σ g
Suma de cubosΣ i³ = [n(n+1)/2]²

Ejemplo 1

Σi=110 5

  1. Es la suma de una constante: Σ c = c n.
  2. Aquí c = 5 y n = 10.
  3. Se multiplica: 5 · 10.

Resultado: 50

Ejemplo 2

Σi=120 i

  1. Se usa Σ i = n(n+1)/2 con n = 20.
  2. Se sustituye: 20 · 21 / 2.
  3. Se calcula: 420 / 2.

Resultado: 210

Ejemplo 3

Σi=110 (3i + 2)

  1. Se separa la suma: 3 Σ i + Σ 2.
  2. Σ i = 10 · 11 / 2 = 55 y Σ 2 = 2 · 10 = 20.
  3. Se sustituye: 3 · 55 + 20 = 165 + 20.

Resultado: 185

Ejemplo 4

Σi=16 i²

  1. Se usa Σ i² = n(n+1)(2n+1)/6 con n = 6.
  2. Se sustituye: 6 · 7 · 13 / 6.
  3. Se simplifica el 6: 7 · 13.

Resultado: 91

Ejemplo 5

Σi=15 (i² − 2i)

  1. Se separa: Σ i² − 2 Σ i.
  2. Con n = 5: Σ i² = 5·6·11/6 = 55 y Σ i = 15.
  3. Se resta: 55 − 2 · 15 = 55 − 30.

Resultado: 25

Suma de Riemann

El área bajo una curva se aproxima con rectángulos de base Δx = (b − a)/n. Los inscritos (sumas inferiores) quedan por debajo de la curva y los circunscritos (sumas superiores) por encima; al aumentar n ambas aproximaciones se acercan al área real.

Ejercicio 2.1 · Aproximación con n rectángulos

Con un número fijo de rectángulos se obtiene una cota inferior y una superior del área.

Ejemplo 1

Aproxima el área bajo f(x) = x² en [0, 2] con n = 4 rectángulos inscritos.

  1. Δx = (2 − 0)/4 = 0.5.
  2. Como f crece, los inscritos usan el extremo izquierdo: x = 0, 0.5, 1, 1.5.
  3. Alturas: 0, 0.25, 1, 2.25; su suma es 3.5.
  4. Área ≈ 3.5 · 0.5.

Resultado: 1.75

Ejemplo 2

Con la misma función y el mismo intervalo, usa rectángulos circunscritos.

  1. Δx = 0.5 y se usa el extremo derecho: x = 0.5, 1, 1.5, 2.
  2. Alturas: 0.25, 1, 2.25, 4; su suma es 7.5.
  3. Área ≈ 7.5 · 0.5.

Resultado: 3.75 (el valor exacto, 8/3 ≈ 2.67, queda entre 1.75 y 3.75)

Ejemplo 3

Para f(x) = x en [0, 4] con n = 4, calcula el área inscrita y la circunscrita.

  1. Δx = 1.
  2. Inscritos: alturas 0, 1, 2, 3 → suma 6 → área 6 · 1 = 6.
  3. Circunscritos: alturas 1, 2, 3, 4 → suma 10 → área 10 · 1 = 10.

Resultado: 6 ≤ área ≤ 10 (el área real del triángulo es 8)

Ejemplo 4

Para f(x) = 2x + 1 en [1, 3] con n = 4, calcula ambas aproximaciones.

  1. Δx = 2/4 = 0.5.
  2. Inscritos: x = 1, 1.5, 2, 2.5 → alturas 3, 4, 5, 6 → 18 · 0.5 = 9.
  3. Circunscritos: x = 1.5, 2, 2.5, 3 → alturas 4, 5, 6, 7 → 22 · 0.5 = 11.

Resultado: 9 ≤ área ≤ 11 (el área exacta es 10)

Ejemplo 5

Para f(x) = x² + 1 en [0, 2] con n = 4, calcula el área inscrita y la circunscrita.

  1. Δx = 0.5.
  2. Inscritos: x = 0, 0.5, 1, 1.5 → alturas 1, 1.25, 2, 3.25 → suma 7.5 → área 3.75.
  3. Circunscritos: x = 0.5, 1, 1.5, 2 → alturas 1.25, 2, 3.25, 5 → suma 11.5 → área 5.75.

Resultado: 3.75 ≤ área ≤ 5.75 (el área exacta es 14/3 ≈ 4.67)

Ejercicio 2.2 · Área con sumas superiores

Sumas superioresA = límn→∞ Σi=1n f(a + iΔx) · (b−a)/n

Fórmulas útiles: Σ 1 = n; Σ i = n(n+1)/2; Σ i² = n(n+1)(2n+1)/6; Σ i³ = n²(n+1)²/4.

Ejemplo 1

Con sumas superiores, halla el área bajo f(x) = 4x + 5 en [2, 5].

  1. Δx = (5 − 2)/n = 3/n, y a + iΔx = 2 + 3i/n.
  2. f(a+iΔx) = 4(2 + 3i/n) + 5 = 13 + 12i/n.
  3. A = límn→∞ Σ (13 + 12i/n)(3/n) = límn→∞ [ (39/n) Σ 1 + (36/n²) Σ i ].
  4. Con Σ 1 = n y Σ i = n(n+1)/2: A = límn→∞ [ 39 + 18(n+1)/n ].
  5. Cuando n → ∞, (n+1)/n → 1, así que A = 39 + 18.

Resultado: A = 57 u²

Ejemplo 2

Halla el área bajo f(x) = x² en [0, 3] con sumas superiores.

  1. Δx = 3/n y a + iΔx = 3i/n.
  2. f(3i/n) = 9i²/n².
  3. A = límn→∞ Σ (9i²/n²)(3/n) = límn→∞ (27/n³) Σ i².
  4. Con Σ i² = n(n+1)(2n+1)/6: A = límn→∞ 27(n+1)(2n+1)/(6n²).
  5. El cociente tiende a 2/6, luego A = 27 · 2/6.

Resultado: A = 9 u²

Ejemplo 3

Halla el área bajo f(x) = x² + 1 en [0, 2] con sumas superiores.

  1. Δx = 2/n y a + iΔx = 2i/n.
  2. f(2i/n) = 4i²/n² + 1.
  3. A = límn→∞ [ (8/n³) Σ i² + (2/n) Σ 1 ].
  4. Se sustituyen las fórmulas: A = límn→∞ [ 8(n+1)(2n+1)/(6n²) + 2 ].
  5. El primer término tiende a 16/6 = 8/3, luego A = 8/3 + 2.

Resultado: A = 14/3 u²

Ejemplo 4

Halla el área bajo f(x) = 3x en [0, 2] con sumas superiores.

  1. Δx = 2/n y a + iΔx = 2i/n.
  2. f(2i/n) = 6i/n.
  3. A = límn→∞ Σ (6i/n)(2/n) = límn→∞ (12/n²) Σ i.
  4. Con Σ i = n(n+1)/2: A = límn→∞ 6(n+1)/n.
  5. Cuando n → ∞, el cociente tiende a 1.

Resultado: A = 6 u²

Ejemplo 5

Halla el área bajo f(x) = x³ en [0, 1] con sumas superiores.

  1. Δx = 1/n y a + iΔx = i/n.
  2. f(i/n) = i³/n³.
  3. A = límn→∞ Σ (i³/n³)(1/n) = límn→∞ (1/n⁴) Σ i³.
  4. Con Σ i³ = n²(n+1)²/4: A = límn→∞ (n+1)²/(4n²).
  5. El cociente tiende a 1/4.

Resultado: A = 1/4 u²

Ejercicio 2.3 · Área con sumas inferiores

Sumas inferioresA = límn→∞ Σi=1n f(a + (i−1)Δx) · (b−a)/n

Ahora se evalúa en el extremo izquierdo de cada subintervalo, por eso aparecen sumas de (i−1): Σ (i−1) = n(n−1)/2, Σ (i−1)² = (n−1)n(2n−1)/6, Σ (i−1)³ = (n−1)²n²/4.

Ejemplo 1

Con sumas inferiores, halla el área bajo f(x) = x² en [0, 3].

  1. Δx = 3/n y a + (i−1)Δx = 3(i−1)/n.
  2. f = 9(i−1)²/n².
  3. A = límn→∞ (27/n³) Σ (i−1)².
  4. Con Σ (i−1)² = (n−1)n(2n−1)/6: A = límn→∞ 27(n−1)(2n−1)/(6n²).
  5. El cociente tiende a 2/6, luego A = 27 · 2/6.

Resultado: A = 9 u² (igual que con sumas superiores)

Ejemplo 2

Halla el área bajo f(x) = 2x + 1 en [0, 3] con sumas inferiores.

  1. Δx = 3/n y a + (i−1)Δx = 3(i−1)/n.
  2. f = 6(i−1)/n + 1.
  3. A = límn→∞ [ (18/n²) Σ (i−1) + (3/n) Σ 1 ].
  4. Con Σ (i−1) = n(n−1)/2: A = límn→∞ [ 9(n−1)/n + 3 ].
  5. Cuando n → ∞: A = 9 + 3.

Resultado: A = 12 u²

Ejemplo 3

Halla el área bajo f(x) = x³ en [0, 2] con sumas inferiores.

  1. Δx = 2/n y a + (i−1)Δx = 2(i−1)/n.
  2. f = 8(i−1)³/n³.
  3. A = límn→∞ (16/n⁴) Σ (i−1)³.
  4. Con Σ (i−1)³ = (n−1)²n²/4: A = límn→∞ 4(n−1)²/n².
  5. El cociente tiende a 1, luego A = 4.

Resultado: A = 4 u²

Ejemplo 4

Halla el área bajo f(x) = x + 3 en [1, 3] con sumas inferiores.

  1. Δx = 2/n y a + (i−1)Δx = 1 + 2(i−1)/n.
  2. f = 4 + 2(i−1)/n.
  3. A = límn→∞ [ (8/n) Σ 1 + (4/n²) Σ (i−1) ].
  4. Se sustituye: A = límn→∞ [ 8 + 2(n−1)/n ].
  5. Cuando n → ∞: A = 8 + 2.

Resultado: A = 10 u²

Ejemplo 5

Halla el área bajo f(x) = x² + 1 en [0, 3] con sumas inferiores.

  1. Δx = 3/n y a + (i−1)Δx = 3(i−1)/n.
  2. f = 9(i−1)²/n² + 1.
  3. A = límn→∞ [ (27/n³) Σ (i−1)² + (3/n) Σ 1 ].
  4. Se sustituye: A = límn→∞ [ 27(n−1)(2n−1)/(6n²) + 3 ].
  5. El primer término tiende a 9: A = 9 + 3.

Resultado: A = 12 u²
