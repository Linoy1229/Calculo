Integrales inmediatas

Definición, fórmulas básicas de integración, cambio de variable y las formas que producen arco tangente, arco seno o logaritmo.

Integrales inmediatas por fórmula directa

Una integral es inmediata cuando coincide —o se hace coincidir mediante un cambio de variable— con alguna de las fórmulas básicas de integración. Nunca debe omitirse la constante de integración C.

Potencia (n ≠ −1)∫ vn dv = vn+1/(n+1) + C
Exponencial base e∫ ev dv = ev + C
Exponencial base a∫ av dv = av/ln a + C

Ejercicio 3 · Integrales con la fórmula de potencias

Resuelve las siguientes integrales de polinomios y potencias.

Ejemplo 1

∫ x⁵ dx

  1. Se aplica la fórmula de potencias: ∫ vn dv = vn+1/(n+1) + C, con n = 5.
  2. Se suma 1 al exponente y se divide entre el nuevo exponente.

Resultado: x⁶/6 + C

Ejemplo 2

∫ (4x³ − 3x² + 2) dx

  1. Se integra cada término por separado (la integral de una suma es la suma de las integrales).
  2. ∫4x³dx = x⁴; ∫3x²dx = x³; ∫2 dx = 2x.
  3. Se combinan los resultados y se agrega la constante.

Resultado: x⁴ − x³ + 2x + C

Ejemplo 3

∫ √x dx

  1. Se escribe la raíz como potencia fraccionaria: √x = x1/2.
  2. Se aplica la fórmula de potencias con n = 1/2, por lo que n+1 = 3/2.
  3. Dividir entre 3/2 equivale a multiplicar por 2/3.

Resultado: (2/3) x3/2 + C

Ejemplo 4

∫ dx/x³

  1. Se escribe 1/x³ como x−3.
  2. Se aplica la fórmula de potencias con n = −3, por lo que n+1 = −2.
  3. Se divide entre −2.

Resultado: −1/(2x²) + C

Ejemplo 5

∫ (2x + 5)⁴ dx

  1. El integrando no es exactamente v⁴ dv, así que se propone v = 2x + 5.
  2. Entonces dv = 2 dx, de donde dx = dv/2.
  3. Se sustituye: ∫ v⁴ (dv/2) = (1/2) ∫ v⁴ dv = v⁵/10.
  4. Se regresa a la variable original.

Resultado: (2x + 5)⁵/10 + C

Ejercicio 4 · Integrales exponenciales

Se usan las fórmulas de exponencial, con cambio de variable cuando el exponente no es simplemente x.

Ejemplo 1

∫ e⁵ˣ dx

  1. Se propone v = 5x, por lo que dv = 5 dx.
  2. Se sustituye: (1/5) ∫ ev dv = (1/5) ev.
  3. Se regresa a la variable original.

Resultado: e⁵ˣ/5 + C

Ejemplo 2

∫ 3e⁻²ˣ dx

  1. La constante 3 sale de la integral.
  2. Con v = −2x, dv = −2 dx, entonces dx = −dv/2.
  3. 3 ∫ ev (−dv/2) = −(3/2) ev.

Resultado: −(3/2) e⁻²ˣ + C

Ejemplo 3

∫ eax+b dx (a, b constantes)

  1. Se propone v = ax + b, por lo que dv = a dx.
  2. Se sustituye: (1/a) ∫ ev dv = (1/a) ev.

Resultado: eax+b/a + C

Ejemplo 4

∫ x ex² dx

  1. Se propone v = x², por lo que dv = 2x dx, es decir, x dx = dv/2.
  2. Se sustituye: (1/2) ∫ ev dv = (1/2) ev.

Resultado: ex²/2 + C

Ejemplo 5

∫ 2³ˣ dx

  1. Se usa la fórmula ∫ av dv = av/ln a + C, con base a = 2.
  2. Con v = 3x, dv = 3 dx, entonces (1/3) ∫ 2v dv = (1/3) · 2v/ln 2.

Resultado: 2³ˣ / (3 ln 2) + C

Ejercicio 5 · Integrales trigonométricas directas

Son las que corresponden a las derivadas de las funciones trigonométricas básicas.

Ejemplo 1

∫ sen 5x dx

  1. Se propone v = 5x, dv = 5 dx.
  2. (1/5) ∫ sen v dv = (1/5)(−cos v).

Resultado: −(1/5) cos 5x + C

Ejemplo 2

∫ cos 4x dx

  1. Se propone v = 4x, dv = 4 dx.
  2. (1/4) ∫ cos v dv = (1/4) sen v.

Resultado: (1/4) sen 4x + C

Ejemplo 3

∫ x sen(x²) dx

  1. Se propone v = x², dv = 2x dx, por lo que x dx = dv/2.
  2. (1/2) ∫ sen v dv = (1/2)(−cos v).

Resultado: −(1/2) cos(x²) + C

Ejemplo 4

∫ sec² 3x dx

  1. Se usa la fórmula inmediata ∫ sec² v dv = tan v + C.
  2. Con v = 3x, dv = 3 dx: (1/3) ∫ sec² v dv = (1/3) tan v.

Resultado: (1/3) tan 3x + C

Ejemplo 5

∫ csc² 2x dx

  1. Se usa ∫ csc² v dv = −cot v + C.
  2. Con v = 2x, dv = 2 dx: (1/2) ∫ csc² v dv = (1/2)(−cot v).

Resultado: −(1/2) cot 2x + C

Integrales que producen arco tangente, arco seno o logaritmo

Cuando el denominador tiene la forma a²±v² (o su raíz), la integral no se resuelve por potencias sino con una de estas tres fórmulas.

Arco tangente∫ dv / (a² + v²) = (1/a) arctan(v/a) + C
Arco seno∫ dv / √(a² − v²) = arcsen(v/a) + C
Logaritmo (v² − a², sin raíz)∫ dv / (v² − a²) = (1/2a) ln |(v−a)/(v+a)| + C

Ejercicio 6 · Identificación directa de a y v

En estos casos a y v se identifican de inmediato, sin manipular el denominador.

Ejemplo 1

∫ dx / (x² + 16)

  1. Es la forma ∫ dv/(a²+v²) = (1/a) arctan(v/a) + C, con a = 4, v = x.

Resultado: (1/4) arctan(x/4) + C

Ejemplo 2

∫ dx / (25 − x²)

  1. Es la forma ∫ dv/(a²−v²) = (1/2a) ln|(a+v)/(a−v)| + C, con a = 5, v = x (nótese: sin raíz).

Resultado: (1/10) ln |(5+x)/(5−x)| + C

Ejemplo 3

∫ dx / (x² − 9)

  1. Es la forma ∫ dv/(v²−a²) = (1/2a) ln|(v−a)/(v+a)| + C, con a = 3, v = x.

Resultado: (1/6) ln |(x−3)/(x+3)| + C

Ejemplo 4

∫ dx / (4x² + 9)

  1. Se identifica a² = 9 (a = 3) y v² = 4x² (v = 2x), con dv = 2 dx.
  2. (1/2) ∫ dv/(a²+v²) = (1/2)(1/3) arctan(v/3).

Resultado: (1/6) arctan(2x/3) + C

Ejemplo 5

∫ dx / √(16 − x²)

  1. Es la forma ∫ dv/√(a²−v²) = arcsen(v/a) + C, con a = 4, v = x.

Resultado: arcsen(x/4) + C

Ejercicio 7 · Con cambio de variable o trinomio cuadrado

Cuando el denominador es un trinomio x²+bx+c, primero se completa el cuadrado para dejarlo como (x+h)² ± k² y así reconocer la fórmula.

Ejemplo 1

∫ dx / (x² + 6x + 13)

  1. El denominador no es un binomio al cuadrado; se completa el trinomio cuadrado perfecto: x²+6x+13 = (x+3)²+4.
  2. Con v = x+3, a = 2, queda la forma ∫ dv/(a²+v²).
  3. Se aplica la fórmula del arcotangente.

Resultado: (1/2) arctan[(x+3)/2] + C

Ejemplo 2

∫ dx / (x² − 4x − 5)

  1. Se completa el cuadrado: x²−4x−5 = (x−2)²−9.
  2. Con v = x−2, a = 3, queda la forma ∫ dv/(v²−a²).

Resultado: (1/6) ln |(x−5)/(x+1)| + C

Ejemplo 3

∫ dx / √(8x − x²)

  1. Se completa el cuadrado dentro de la raíz: 8x−x² = 16−(x−4)².
  2. Con v = x−4, a = 4, queda la forma ∫ dv/√(a²−v²).

Resultado: arcsen[(x−4)/4] + C

Ejemplo 4

∫ dx / (9x² + 6x + 2)

  1. Se factoriza 9 y se completa el cuadrado: 9x²+6x+2 = 9(x+1/3)²+1.
  2. Equivalente a (3x+1)²+1, con v = 3x+1, a = 1, dv = 3 dx.

Resultado: (1/3) arctan(3x+1) + C

Ejemplo 5

∫ (2x + 3) / (x² + 3x + 5) dx

  1. El numerador es exactamente la derivada del denominador: d/dx(x²+3x+5) = 2x+3.
  2. Es la forma inmediata ∫ du/u = ln|u| + C, con u = x²+3x+5.

Resultado: ln (x² + 3x + 5) + C
