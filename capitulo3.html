Integrales de diferenciales trigonométricas

Potencias de seno, coseno, tangente, cotangente, secante y cosecante; productos de senos y cosenos de ángulos distintos.

Potencias impares de seno y coseno

El libro agrupa estos ejercicios en la sección de potencias de funciones trigonométricas. Cuando el exponente de seno o de coseno es impar, se separa un factor de esa función para formar la diferencial y el resto se transforma con sen²x + cos²x = 1.

Caso: exponente impar∫ sennx dx = ∫ senn−1x · sen x dx = ∫ (1−cos²x)(n−1)/2 sen x dx

Ejercicio 8 · Potencias impares de seno y coseno

Ejemplo 1

∫ sen³x dx

  1. El exponente de seno es impar (3); se separa un factor: sen³x = sen²x · senx.
  2. Se usa sen²x = 1 − cos²x, y se propone v = cosx, dv = −senx dx.
  3. ∫(1−v²)(−dv) = −∫dv + ∫v²dv = −v + v³/3.

Resultado: −cos x + (1/3) cos³x + C

Ejemplo 2

∫ cos⁵x dx

  1. El exponente de coseno es impar (5): cos⁵x = cos⁴x · cosx = (cos²x)² · cosx.
  2. Se usa cos²x = 1 − sen²x y se propone v = senx, dv = cosx dx.
  3. ∫(1−v²)²dv = ∫(1 − 2v² + v⁴)dv = v − (2/3)v³ + (1/5)v⁵.

Resultado: sen x − (2/3) sen³x + (1/5) sen⁵x + C

Ejemplo 3

∫ sen³x cos²x dx

  1. El exponente de seno es impar; se separa senx y se deja cos²x intacto: sen²x cos²x senx dx.
  2. Con sen²x = 1−cos²x y v = cosx, dv = −senx dx: ∫(1−v²)v²(−dv).
  3. = −∫(v² − v⁴)dv = −v³/3 + v⁵/5.

Resultado: −(1/3) cos³x + (1/5) cos⁵x + C

Ejemplo 4

∫ sen²x cos³x dx

  1. Ahora el exponente impar es el de coseno (3); se separa cosx: cos²x senx² cosx dx... se deja sen²x y cos²x cosx dx.
  2. Con cos²x = 1−sen²x y v = senx, dv = cosx dx: ∫v²(1−v²)dv.
  3. = ∫(v² − v⁴)dv = v³/3 − v⁵/5.

Resultado: (1/3) sen³x − (1/5) sen⁵x + C

Ejemplo 5

∫ cos³2x dx

  1. Exponente impar con ángulo múltiple: cos³2x = cos²2x · cos2x = (1−sen²2x)cos2x.
  2. Se propone v = sen2x, dv = 2cos2x dx, es decir cos2x dx = dv/2.
  3. (1/2)∫(1−v²)dv = (1/2)(v − v³/3).

Resultado: (1/2) sen 2x − (1/6) sen³2x + C

Potencias de tangente y cotangente

Se usa tan²x = sec²x − 1 (o cot²x = csc²x − 1) para separar un factor sec²x o csc²x, que es inmediato, y reducir el exponente restante.

Identidad clavetan²x = sec²x − 1    cot²x = csc²x − 1

Ejercicio 9 · Potencias de tangente y cotangente

Ejemplo 1

∫ tan³x dx

  1. Se separa tan²x: tan³x = tanx · tan²x, y se usa tan²x = sec²x − 1.
  2. ∫tanx(sec²x−1)dx = ∫tanx sec²x dx − ∫tanx dx.
  3. La primera es inmediata con v=tanx; la segunda es −ln|cosx|.

Resultado: (1/2) tan²x + ln |cos x| + C

Ejemplo 2

∫ cot³x dx

  1. De forma análoga, cot³x = cotx(csc²x − 1).
  2. ∫cotx csc²x dx − ∫cotx dx, con v = cotx en la primera.

Resultado: −(1/2) cot²x − ln |sen x| + C

Ejemplo 3

∫ tan⁴x dx

  1. Se separa tan²x: tan⁴x = tan²x(sec²x − 1) = tan²x sec²x − tan²x.
  2. ∫tan²x sec²x dx es inmediata (v=tanx); para ∫tan²x dx se usa de nuevo tan²x=sec²x−1.
  3. tan³x/3 − (tanx − x).

Resultado: (1/3) tan³x − tan x + x + C

Ejemplo 4

∫ cot⁴x dx

  1. cot⁴x = cot²x(csc²x − 1) = cot²x csc²x − cot²x.
  2. ∫cot²x csc²x dx es inmediata; ∫cot²x dx = ∫(csc²x−1)dx = −cotx − x.

Resultado: −(1/3) cot³x + cot x + x + C

Ejemplo 5

∫ tan³2x dx

  1. Con ángulo múltiple: tan³2x = tan2x(sec²2x − 1).
  2. ∫tan2x sec²2x dx − ∫tan2x dx, con v = 2x en cada cambio.

Resultado: (1/4) tan²2x + (1/2) ln |cos 2x| + C

Potencias de secante y cosecante

Cuando el exponente de secante o cosecante es par, se separa sec²x (o csc²x) para la diferencial y el resto se transforma con 1+tan²x = sec²x.

Identidad clavesec²x = 1 + tan²x    csc²x = 1 + cot²x

Ejercicio 10 · Potencias de secante y cosecante

Ejemplo 1

∫ sec⁴x dx

  1. Se separa sec²x: sec⁴x = sec²x · sec²x, y se usa sec²x = 1 + tan²x en el primer factor.
  2. ∫(1+tan²x) sec²x dx, con v = tanx, dv = sec²x dx.
  3. ∫(1+v²)dv = v + v³/3.

Resultado: tan x + (1/3) tan³x + C

Ejemplo 2

∫ csc⁴x dx

  1. csc⁴x = csc²x · csc²x = (1+cot²x) csc²x.
  2. Con v = cotx, dv = −csc²x dx: −∫(1+v²)dv = −(v+v³/3).

Resultado: −cot x − (1/3) cot³x + C

Ejemplo 3

∫ sec⁴2x dx

  1. sec⁴2x = (1+tan²2x) sec²2x, con v = tan2x, dv = 2sec²2x dx.
  2. (1/2)∫(1+v²)dv = (1/2)(v+v³/3).

Resultado: (1/2) tan 2x + (1/6) tan³2x + C

Ejemplo 4

∫ csc⁴3x dx

  1. csc⁴3x = (1+cot²3x) csc²3x, con v = cot3x, dv = −3csc²3x dx.
  2. −(1/3)∫(1+v²)dv = −(1/3)(v+v³/3).

Resultado: −(1/3) cot 3x − (1/9) cot³3x + C

Ejemplo 5

∫ tan²x sec⁴x dx

  1. Se deja sec²x para formar dv y se transforma el resto: tan²x sec²x · sec²x = tan²x(1+tan²x) sec²x.
  2. Con v = tanx, dv = sec²x dx: ∫v²(1+v²)dv = ∫(v²+v⁴)dv.

Resultado: (1/3) tan³x + (1/5) tan⁵x + C

Potencias pares de seno y coseno

Cuando el exponente es par y no hay un factor impar que separar, se usan las identidades de ángulo medio, aplicándolas una o varias veces según el exponente.

Identidades de ángulo mediosen²x = (1 − cos 2x)/2    cos²x = (1 + cos 2x)/2

Ejercicio 11 · Potencias pares de seno y coseno

Ejemplo 1

∫ sen²x dx

  1. El exponente es par; se usa la identidad de ángulo medio sen²x = (1−cos2x)/2.
  2. ∫(1/2)dx − ∫(1/2)cos2x dx = x/2 − (1/4)sen2x.

Resultado: x/2 − (1/4) sen 2x + C

Ejemplo 2

∫ cos²x dx

  1. Se usa cos²x = (1+cos2x)/2.
  2. ∫(1/2)dx + ∫(1/2)cos2x dx = x/2 + (1/4)sen2x.

Resultado: x/2 + (1/4) sen 2x + C

Ejemplo 3

∫ sen⁴x dx

  1. sen⁴x = (sen²x)² = [(1−cos2x)/2]² = (1/4)(1 − 2cos2x + cos²2x).
  2. Se integra cos²2x con la misma identidad de ángulo medio otra vez: cos²2x = (1+cos4x)/2.
  3. Al desarrollar y simplificar se agrupan los términos.

Resultado: (3/8)x − (1/4) sen 2x + (1/32) sen 4x + C

Ejemplo 4

∫ cos⁴x dx

  1. cos⁴x = [(1+cos2x)/2]² = (1/4)(1 + 2cos2x + cos²2x), con cos²2x = (1+cos4x)/2 de nuevo.

Resultado: (3/8)x + (1/4) sen 2x + (1/32) sen 4x + C

Ejemplo 5

∫ sen²3x dx

  1. Se usa sen²3x = (1−cos6x)/2 (el ángulo doble de 3x es 6x).
  2. ∫(1/2)dx − (1/2)∫cos6x dx = x/2 − (1/12)sen6x.

Resultado: x/2 − (1/12) sen 6x + C

Productos de senos y cosenos de ángulos distintos

Cuando el integrando es un producto como sen mx · cos nx, con ángulos diferentes, se convierte en una suma con las identidades de producto a suma, y cada término se integra de forma inmediata.

Identidades de producto a sumasen A cos B = ½[sen(A+B) + sen(A−B)]
sen A sen B = ½[cos(A−B) − cos(A+B)]
cos A cos B = ½[cos(A−B) + cos(A+B)]

Ejercicio 12 · Productos sen mx · cos nx y similares

Ejemplo 1

∫ sen 2x cos 3x dx

  1. Se usa sen A cos B = (1/2)[sen(A+B) + sen(A−B)], con A=2x, B=3x.
  2. sen5x + sen(−x) = sen5x − senx; se integra cada término.
  3. ∫(1/2)(sen5x − senx)dx = (1/2)[−cos5x/5 + cosx].

Resultado: −(1/10) cos 5x + (1/2) cos x + C

Ejemplo 2

∫ sen 4x sen 2x dx

  1. Se usa sen A sen B = (1/2)[cos(A−B) − cos(A+B)], con A=4x, B=2x.
  2. (1/2)[cos2x − cos6x]; se integra cada término.

Resultado: (1/4) sen 2x − (1/12) sen 6x + C

Ejemplo 3

∫ cos 5x cos 3x dx

  1. Se usa cos A cos B = (1/2)[cos(A−B) + cos(A+B)], con A=5x, B=3x.
  2. (1/2)[cos2x + cos8x]; se integra cada término.

Resultado: (1/4) sen 2x + (1/16) sen 8x + C

Ejemplo 4

∫ sen 5x cos 2x dx

  1. sen A cos B = (1/2)[sen(A+B)+sen(A−B)], con A=5x, B=2x.
  2. (1/2)[sen7x + sen3x]; se integra cada término.

Resultado: −(1/14) cos 7x − (1/6) cos 3x + C

Ejemplo 5

∫ cos 2x sen 4x dx

  1. Es sen4x cos2x: sen A cos B, con A=4x, B=2x.
  2. (1/2)[sen6x + sen2x]; se integra cada término.

Resultado: −(1/12) cos 6x − (1/4) cos 2x + C
